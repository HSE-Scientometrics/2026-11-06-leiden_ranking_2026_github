# CWTS Leiden Ranking 2026 — дашборд

Интерактивный обзор мирового рейтинга и российских университетов. Интерфейс, фильтры, графики, карточки вузов и выгрузка таблиц используют русские названия университетов и стран.

## Содержание

- **Общий рейтинг** — лидеры по выбранному показателю, таблица организаций, фильтр по странам и выгрузка среза в CSV.
- **Россия** — места вузов в России и мире, показатели с интервалами устойчивости, динамика и раскрываемые карточки университетов. При смене общих фильтров автоматически выбираются пять лидеров текущего российского среза; список можно изменить.
- **Страновые сравнения** — состав настраиваемого топ-N (по умолчанию 10) и динамика выбранных стран по объёму публикаций и выбранному показателю.
- **Сравнение организаций** — значения и места выбранных университетов во времени; по умолчанию выбраны пять российских лидеров текущего среза, список можно заменить или дополнить.
- **Методика** — объяснение показателей, правил подсчёта, охвата и ограничений данных.

Фильтры расположены над вкладками. По умолчанию установлен порог 100 публикаций; в выборку входят все университеты, прошедшие его. Выбраны все науки, последний опубликованный период и показатель публикаций P. CWTS применяет дробный подсчёт для показателей научного влияния и полный — для сотрудничества, открытого доступа и авторств.

## Запуск на компьютере

Нужен Python 3.12 или новее.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

## Размещение на Streamlit Community Cloud

Приложение запускается из корневой папки репозитория; точка входа — `app.py`. Чтобы опубликовать его:

1. Создайте пустой репозиторий GitHub.
2. Установите [Git LFS](https://git-lfs.com/), откройте эту папку в терминале и выполните:

   ```powershell
   git lfs install
   git init
   git add .gitattributes
   git add .
   git commit -m "Add Leiden Ranking dashboard"
   git branch -M main
   git remote add origin https://github.com/<пользователь>/<репозиторий>.git
   git push -u origin main
   ```

   Файл данных уже отмечен в `.gitattributes` для Git LFS.
3. Войдите в [Streamlit Community Cloud](https://share.streamlit.io/), подключите репозиторий и выберите `app.py` как основной файл приложения.

Файл данных превышает ограничение GitHub для обычного Git-файла, поэтому для него требуется Git LFS. Streamlit Community Cloud поддерживает репозитории с LFS.
